# 自主核心记忆开发评估

日期：2026-11-01。本文为现有代码评估和后续设计建议，尚未实现的功能均为建议，不表示已经上线。

## 实施进展（1.2.0）

用户已确认此方向。第一阶段现已实现核心数据层、`love_core_memory` 模型工具、版本及整体校验、快照、私聊/群聊隔离、召回与主图显式核心适配、核心文件导入导出。新对象使用稳定 ID；旧文件继续兼容，尚未统一迁移。

具体字段及边界见 [工具说明](../plugin/docs/CORE-MEMORY.md)。下表和开发顺序保留为最初评估；会话后的自动提炼、定期整理、全库语义召回、完整冲突生命周期及稳定坐标仍未实现。格式校验不等于自动验证来源真实性。

1.3.0 已补齐旧图谱记忆的预览、稳定内容引用、迁入模型所选核心、图谱/召回去重及逐条撤回；未强制迁移真实数据。覆盖范围和局限、12 组验证、下一轮计划及意见见 [本轮评估](reports/1.3.0-memory-migration.md)。用户要求后续每轮都提交独立评估，索引见 [报告目录](reports/README.md)。

## 用户当前确认的规则

- 保留当前定稿的连接和视觉方案。同分区记忆星可互连；分支核心可互连；跨分区星点关联通过分支核心汇总表达。
- 自我是唯一总核心，也可以直接拥有组成自我的记忆星；分支核心与普通记忆维持现有层级和视觉优先级。
- 她决定核心的名称、含义、内容、记忆归属和有依据的关联；插件校验层级、格式、引用及保存一致性。
- “分支星只能连接核心”已被用户明确废弃，不应再作为待修复的问题。

## 建议的权责

她负责决定：什么值得记、如何理解这段经历、归属哪个核心、是否形成新核心、如何概括自我、核心之间有什么关联，以及何时提出合并/修改/归档。

插件负责落实：结构化工具输入、类型及长度检查、有效引用、唯一自我根节点、父子层级无环、跨分区关系转换、私聊/群聊与工作区范围、原子保存、版本和失败回滚。

坐标由布局器计算。她决定语义位置（归属、关联、重要性），插件将其投影成稳定的三维位置；不要求模型输出像素或坐标。

## 需要持久化的对象

建议统一逻辑记录格式，先兼容现有文件与 meow，不立即强制迁移所有存储。

- 核心：稳定 ID、种类（self/branch）、名称、摘要、形成理由、来源记忆 ID、上级 ID、版本、状态、时间。
- 记忆：稳定 ID、正文、种类（事件/事实/偏好/反思等）、主要归属核心、重要性及理由、来源会话/消息、事实或推测标记、时间、有效期、取代/被取代记录。
- 关联：两端 ID、关系类型、解释及依据。普通记忆的跨分区关联保留在数据层，星图以核心间汇总连线表达。
- 所有权与范围：工作区、私聊/群聊及群号。角色标签和数据来源不再决定星图核心，仍可供筛选。

核心建议是她对一组重要经历形成的持续认识，不只是某条记忆的重要度达到阈值就自动放大的节点。

## 建议的处理流程

对话/真实活动结果 → 候选记忆 → 她检查已有核心并决定记录/归属/新建/修正 → 结构化变更集 → 插件校验 → 原子提交及变更日志 → 检索、心情、星图读取同一份有效记忆。

记忆整理采取增量批次，避开每次心跳都调用模型。模型提出操作时引用已有 ID，新增 ID 由插件分配；校验失败返回具体字段错误供重试，失败变更不产生半套核心或悬空连线。

反思内容标记为她的理解，不能当作对方确认的事实；没有真实阅读/浏览工具结果时，活动标签不能变成“已经学到了某知识”的来源。

## 开发顺序

1. 建立核心/记忆/关联契约、稳定 ID、版本和验证器；为现有记录建立兼容映射，不制造新事实。
2. 增加模型可调用的创建核心、记录并归属、关联、修正、合并/归档工具；更新模型使用说明，使其先检查已有核心，再决定如何变更。
3. 主图从显式核心和归属读取，停用 layer 自动建核心；保留当前动画、连接汇总、详情、搜索和图层筛选。为旧记录提供可回退的迁移。
4. 加入会话后的增量提炼与定期整理，发展由经历支撑的自我摘要，处理重复与事实变更。
5. 建立独立语义召回并与关键词、实体、核心路径和时间检索合并；让有效记忆参与情绪解释与主动行为。

## 验收场景

- 新经历可由她提出新核心，名称/内容不是写死的类型名。
- 相似经历优先进入已有核心，不在每轮对话里重复建核心。
- 格式错误、未知核心 ID、循环层级和悬空关联不会部分写入。
- 自我记忆能指向具体经历，重要程度及提升理由可查看。
- 同分区星点关系可见，跨区关系仍按当前定稿经核心汇总。
- 偏好改变时当前事实更新，旧经历作为历史保留并能解释变化。
- 重启、排序或归档不会改变记录身份；星图刷新维持稳定布局基点。
- 重复/不相关记录能整理，推测不会在反复总结后变成已确认事实。
- 情绪能追溯到有效记忆；修正触发记忆后会重新评估其影响。
- 多工作区与群聊数据保持范围一致，导入导出覆盖新增对象。

## 结论

现有插件已有可用的表现、记录、检索和互动基础，但自主核心记忆尚未形成闭环。下一阶段应先实现“她可以提交核心与记忆的结构化变更，插件验证并可靠保存”，再接入自动整理；继续调整星图动画不是当前重点。
