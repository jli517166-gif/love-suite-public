# 隐私与数据边界

这是 `love-suite` 的公开快照，从开发仓库的 `1.16.0` 工作树导出。

- 不包含开发仓库的 Git 历史
- 不包含真实 `memory/`、日记、聊天数据库、发件箱或会话文件
- 不包含 `.env`、凭据、私钥、证书或 npm token
- 不包含私人照片、录音、视频
- 星图素材 `plugin/star/assets/m83.jpg` 是公开星系图；UI 截图不含昵称或 QQ

## 贡献时不要提交

- 真实工作区的 `memory/`
- 任何 QQ 号、群号、昵称、聊天正文
- 本机绝对路径、日志、备份
- `.env`、token、cookie、私钥、证书
- 含个人信息的截图

如果你要报告问题，请先删除聊天原文和账号信息，只保留复现所需的最小内容。

当前是测试阶段，隐私边界和数据处理仍可能变化；不要把这个仓库当成稳定记忆服务。
