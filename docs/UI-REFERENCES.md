# UI 参考与决策（2026-10-31）

## 看过的参考

| 参考 | 看了什么 | 采用/放弃 |
|---|---|---|
| DSH 宿主侧边栏（better-sidebar 截图） | 浅色、细线、图标栏、内容单列、12–13px 字号、留白大 | 采用“单列 + 细线 + 留白”，放弃图标栏（插件面板太窄） |
| [DSH-better-sidebar](https://github.com/omdsh-dev/DSH-better-sidebar) | 文件树、Git 面板都是“列表 + 状态色”，没有大卡片 | 采用列表式群友/记忆，不做卡片堆 |
| [whale-girl](https://github.com/vlln/whale-girl) | 角色本身是视觉中心，UI 退到后面 | 保留“整理小本子，开心”这种拟人标题，但不做卡通装饰 |
| [openpets](https://github.com/openpetshq/openpets) | 桌面宠物式交互，重动画 | 暂不采用，插件里动画越少越稳 |
| DSH 宿主 GUI | 白底、极简、无重阴影 | 采用白底 + 细边框 + 单一强调色 |

## 设计决策

- **不做左侧导航栏**：设置页字段多，左栏会把内容挤窄；改回顶部页签 + 单列内容，最大 820px。
- **单一强调色**：海玻璃青 `#2f9e8f`；不再用紫色按钮。
- **标题两级**：面板标题 20px；内容里的“此刻”保留衬线，作为唯一有个性的地方。
- **私聊 / 群聊是上下文，不是页签**：右上角切换；群聊下再选具体群。
- **设置用横线分组**：去掉卡片边框和阴影，只留 1px 分隔线。
- **不做入场动画**：面板是工具，稳定优先。
